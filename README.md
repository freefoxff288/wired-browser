# ✦ Wired Browser

Браузер на Chromium (QtWebEngine) в стиле *Serial Experiments Lain*. Без паролей, закладок, истории и прочего лишнего — только вкладки, красивые анимации и темы.

## Установка на Windows

1. Открой **[Releases](../../releases/latest)** и скачай `WiredBrowser-windows-x64.zip`.
2. Распакуй в любую папку (например, `C:\Programs\WiredBrowser`).
3. Запусти `WiredBrowser.exe`.

Windows может показать «Система Windows защитила ваш компьютер» — у программы нет платной подписи. Нажми **Подробнее → Выполнить в любом случае**.

Нужна 64-битная Windows 10 или 11.

## Что умеет

- **Вкладки**: перетаскивание мышью, закрепление и дублирование (правый клик по вкладке).
- **Пять тем**: WIRED, PSYCHE, NAVI, COPLAND, KNIGHTS — цвета плавно перетекают при смене.
- **Главная страница**: часы, поиск, быстрые ссылки (правый клик — изменить, «+» — добавить).
- **Загрузки**: кнопка справа от адресной строки, кольцо прогресса.
- **Прокрутка нажатием колеса мыши**, как в Windows-браузерах.
- **Настройки** (шестерёнка или `Ctrl+,`): тема, анимации, поисковик, главная, масштаб, папка загрузок.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+T` / `Ctrl+W` | новая / закрыть вкладку |
| `Ctrl+Tab` | следующая вкладка |
| `Ctrl+L` | адресная строка |
| `Ctrl+F` | поиск на странице |
| `Ctrl+J` | загрузки |
| `Ctrl+,` | настройки |
| `Ctrl +/-/0` | масштаб |
| `Alt+←/→` | назад / вперёд |
| `F5` | обновить |
| `F11` | полный экран |

## Linux

Сборка не нужна, нужен Qt 6.9+ с QtWebEngine:

```sh
/usr/lib/qt6/bin/qml src/browser.qml -- [адрес]
```

## Сборка из исходников

Windows-zip собирает GitHub Actions (`.github/workflows/build.yml`) при каждом теге `v*`.
Вручную: Qt 6.9+ (модули WebEngine, WebChannel, Positioning), затем `cmake -S . -B build && cmake --build build --config Release` и `windeployqt`.
